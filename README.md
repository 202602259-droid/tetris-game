# Tetris Game 🎮

A simple playable Tetris game built with **HTML, CSS, and JavaScript**. No frameworks or installation are required.

## Features
- Classic 10 × 20 Tetris board
- Seven tetromino shapes
- Move, rotate, soft drop, and hard drop
- Score and line counter
- Next-piece preview
- Pause and restart
- Responsive layout
- Works directly in a web browser

## Controls
| Key | Action |
|---|---|
| ← / → | Move |
| ↓ | Soft drop |
| ↑ | Rotate |
| Space | Hard drop |
| P | Pause / Resume |
| R | Restart |

## Run locally
Open `index.html` in a modern web browser.

## GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish the game.
